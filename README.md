# PT Shoes

Bilingual static landing page for unbranded footwear and bag style selection.

## Contact configuration

- Telegram: `https://t.me/web3liuge`
- WhatsApp: copy-only ID `btc188`; do not create a `wa.me` link unless an international phone number is available.

## Content rules

- Product illustrations are style references, not live inventory.
- Do not claim brand affiliation, authorization, authenticity, factory-direct sourcing, stock, delivery speed, or return terms unless they can be verified for the specific order.
- Replace reference illustrations with current item photos only when usage rights and the item details are documented.
- Keep English and Chinese text aligned whenever content changes.

## Deployment

The site is deployed on Vercel. Pushes to `main` auto-deploy to production, so changes should be reviewed through a pull request first.

## Pre-deploy checks

1. Search for invalid or old contacts: `wa.me`, `andylbd`, and `btc188` used as a URL.
2. Check mobile layouts at 360px and 768px widths.
3. Test language switching, product filters, Telegram links, and copy buttons.
4. Confirm every visible business claim is current and supportable.
